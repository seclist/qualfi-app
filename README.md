# Qualfi — Bespoke Diagnostic Micro-Tools for Fitness Coaches

> **“DM me READY” was never a funnel.**

Qualfi replaces Linktree and generic link-farms with bespoke 60-second diagnostic micro-tools in the coach's bio. Followers receive immediate personalized caloric targets, macronutrient splits, and workout schedules. Behind the curtain, each lead is algorithmically scored from 0 to 100 on intent, and hot leads are dispatched directly to the coach's personal WhatsApp in under 2 seconds.

---

## Aesthetic & Design Philosophy (Kiln + Moss Fusion)

- **Art Direction**: Wabi-Sabi organic naturalism elevated with contemporary Awwwards editorial restraint.
- **Palette**:
  - Ceramic Bone Canvas: `#F4EFE6`
  - Terracotta Clay: `#B5654A`
  - Organic Lichen Sage: `#6C7C3F`
  - Deep Espresso Charcoal: `#231D17`
  - Apricot Highlight: `#E8A87C`
- **Typography**:
  - Display: `Fraunces` (Editorial serif with italic flourishes)
  - Interface & Body: `Plus Jakarta Sans`
- **Key Interactivity & Animation Principles**:
  - Masked word-by-word headline reveals with ease-out timing.
  - Hand-drawn SVG Enso arc that draws around the `<2s` WhatsApp stat.
  - Interactive phone-in-pocket simulator with coach header and step-by-step diagnostic.
  - Tactile weight knob with 12% stretch on drag and rubber-band elasticity.
  - Asymmetrical ceramic pebble buttons with shared `layoutId` gliding highlight.
  - The signature **Swooping WhatsApp Lead Card**: The lead notification flies out of the phone in an arc upon quiz completion with a pulsing green checkmark and simulated live conversation modal.
  - Dynamic strike-through animations over obsolete traditions (*Linktree*, *Static forms*, *“DM me READY”*).

## Getting Started

Run the development server on localhost:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

To create an optimized production build:

```bash
npm run build
npm run start
```
